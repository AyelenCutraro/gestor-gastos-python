# gestor-gastos-python
Sistema de gestión de gastos personales desarrollado con Python y SQLite 
Gestor de Gastos Personales

Proyecto de práctica desarrollado para fortalecer mis conocimientos de Python y bases de datos SQL.

Objetivo

Crear una aplicación que permita registrar y consultar gastos personales, organizarlos por categoría y calcular totales.

Tecnologías

- Python
- SQLite
- SQL
- Git y GitHub

Funcionalidades planificadas

- Registrar gastos.
- Consultar los gastos registrados.
- Clasificar gastos por categoría.
- Calcular el total de gastos.
- Almacenar la información en una base de datos SQLite.

Estado del proyecto

En desarrollo.
